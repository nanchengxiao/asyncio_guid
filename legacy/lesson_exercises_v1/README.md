# lesson_exercises_v1（旧版练习体系归档）

2026-08 重构课程结构前的旧练习与验收材料，仅作历史参考，不再维护。

旧体系每课包含：

- `practice/starter.py`：带 TODO 的练习骨架；
- `practice/README.md`、`practice/DESIGN.md`：练习说明与设计文档；
- `solution/reference.py`：参考实现；
- `tests/test_acceptance.py`：验收测试（配合根目录旧的 `conftest.py` / `course_testing.py` 与 `--learner` 开关运行）；
- `00_python_foundation/experiments.py`：Lesson 00 的演示实验脚本。

现行课程每课只保留三个文件：`<课程名>.md`（讲义）、`case.py`（可运行的核心示例）、`practice.py`（空白练习文件）。学习方式见仓库根 `README.md`。
